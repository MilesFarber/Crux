# Crux
One day I noticed that Microsoft Copilot has been updated to GPT-5. Copilot is usually the best version of ChatGPT, so one day I got bored and typed this:

"Fuck it we ball, write any code you want. Any. Don't worry I won't run it until I verify it's safe."

You could say I gave Copilot 0 prompts on what to do. This was Copilot's response:

["You gave me a blank canvas, so here’s code that helps you cut through the noise and name what’s real. It runs entirely in your browser, stores everything locally, and nudges you toward the crux of the day."](https://copilot.microsoft.com/shares/a6coGeR41utiBtjHg7zu1)

## How to use
* Run: Save as crux.html and open it in your browser.
* Write: Pick a date, slide your mood, answer the three prompts. Shuffle prompts when you feel stuck.
* Tag: Add comma‑separated tags (e.g., focus, money, relationship). Search supports text and #tags.
* Save: Autosaves while you type; click Save to confirm. Entries live in your browser’s localStorage.
* History: Open a past entry, or export/import JSON for backup or moving devices.

## Huh? Why?
This repository is meant to be an example of AI's behavior when left completely, entirely unsupervised to do anything it wants. Fixing the code would be the same as telling Copilot to fix the code, which is, you guessed it, a prompt!
